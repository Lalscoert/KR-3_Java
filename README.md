# Практические работы №9–12 по Java

Репозиторий содержит четыре консольных приложения на Java. Каждая практическая находится в отдельной папке и включает исходный код, автоматические проверки и документацию.

## Содержание

| Работа | Тема | Реализовано |
|---|---|---|
| №9 — Склад оборудования | Коллекции `Map`, `List`, `Set` | Учёт остатков, приход и выдача, уникальные инвентарные коды, поиск по категориям, история операций |
| №10 — Система доставки | Интерфейсы и полиморфизм | Четыре стратегии доставки, фабрика выбора стратегии, расчёт стоимости и проверка ограничений |
| №11 — Импорт клиентов | Файлы, CSV, исключения | Чтение CSV, проверка ИНН и email, обработка дубликатов, отчёт об успешных и ошибочных строках |
| №12 — Аналитика продаж | Stream API, Comparator, Optional | Сортировка и фильтрация продаж, максимальная продажа, выручка по менеджерам, итоговые показатели |

## Запуск

Требуется **JDK 17 или новее**. Команды выполняются в терминале PowerShell из корневой папки репозитория.

Пример запуска практической №9:

```powershell
javac .\practice-09\src\*.java
java -cp .\practice-09\src Main
```

Для практических №10, №11 и №12 замените `practice-09` на соответствующий номер. Практическая №11 при запуске без указанного пути читает `practice-11/data/sample.csv`.

## Автоматические проверки

После компиляции каждого проекта запустите его класс `SelfCheck`:

```powershell
java -cp .\practice-09\src SelfCheck
```

Аналогично выполняются проверки для остальных практических. Успешный запуск выводит количество пройденных проверок и `Ошибок: 0`.
